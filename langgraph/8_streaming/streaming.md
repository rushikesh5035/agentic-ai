### Streaming

In the context of Large Language Models (LLMs), streaming is a technique where the model sends output tokens to the user as soon as they are generated, rather than waiting for the entire response to be completed

#### Why streaming is important:

- **Faster perceived response time:** It prevents the screen from appearing blank for several seconds while the model thinks, making the application feel responsive and preventing users from thinking the app has frozen
- **Human-like interaction:** It mimics natural conversation, which builds user trust and keeps them engaged
- **Improved readability:** For long outputs like code or detailed blog posts, seeing the text appear in a "typewriter" fashion makes the content easier to process compared to a sudden, large block of text
- **Efficiency and cost savings:** It allows users to stop a response mid-way if they aren't satisfied, which can save tokens and reduce costs since they aren't forced to generate the entire output
